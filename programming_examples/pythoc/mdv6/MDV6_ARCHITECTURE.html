4 · Optimization timeline

  • Vectorized SiLU — scalar f32 soft-float libcalls in BN+SiLU were 94% of every dispatch; 32-wide bf16 reciprocal sigmoid fixed it (gemm 5.7 → 0.8 ms).
  • Halo chains — all 14 bottleneck-stack iterations × 3 geometries = one launch each; ~2 ms/iter inside.
  • aconv5 chunked OCB — full unroll exceeds the ~40-iteration compile limit; half-layer ELF ×2 collapses 24 → 2 launches.
  • rnm epilogue (in flight) — numerics validated (0.012 mean = bf16 96-term quantization); model run pending wedge-free window.

5 · Remaining levers

gemm 1×1 swarm — ~48 launches × 1.2 ms ≈ 60 ms. Sequential dependence kills host pipelining; recipe = pull rn1 prologue + rnm into chain launches (rn1: ~14 more) · re4/re8 epilogues — drain-BD reduction (re4) + width trim (re8) · 3×3 NPU-active — mc_re4_c3/ftconv1/re6_c3 ~54 ms across 14 calls = shim DMA bandwidth (~0.5 GB/s vs 22 GB/s passthrough) · mmul shuffle bloat — 27 shuffles per mmul, ~4× kernel headroom.
